# NoteFlow AI – توثيق تنفيذ المرحلة الثانية

**مرشح مصدر مفتوح للإصدار `1.1.0`، وليس APK مُختبراً.**
**التاريخ: 2026-11-18** · الترخيص: Apache-2.0.

## الملخص التقني

التطبيق واحد لثلاث فئات: محاضرة (طلاب)، اجتماع (موظفون ومديرون)، بحث/تدريب (باحثون ومتدربون). الواجهة Kotlin/Compose، والبيانات Room v4 مع ترحيل 3→4، والتسجيل في خدمة أمامية بقطع M4A محلية، ومعالجة اختيارية على خادم FastAPI. لا تحتاج المكتبة والتسجيل إلى حساب أو خادم. جميع وظائف الخادم تمر عبر HTTPS وتتطلب إقرار المستخدم بموافقته على معالجة الجلسة.

## الترجمة

رموز اللغات المدعومة: `ar`, `en`, `fr`, `es`, `de`, `tr`, `it`, `pt`, `hi`, `ur`, `zh`, `ja`, `ko`, `ru`. تُعرَض المصطلحات التقنية ضمن نصها الأصلي. يتغير هدف الترجمة لكل جلسة في تبويب النص، وتختار اللغة المطلوبة عند بدء التسجيل. يضمن الخادم قبول الرموز المعروفة فقط.

## قواعد البيانات الجديدة – Room v4

- `sessions.translationTarget`: لغة الترجمة المختارة للجلسة، افتراضياً `en`.
- `speaker_turns`: `id`, `sessionId`, `segmentId`, `speaker`, `startMs`, `endMs`, `text`.
- `quiz_questions`: `id`, `sessionId`, `question`, `optionsJson`, `correctIndex`, `sourceIdsJson`, `chosenIndex`.
- الترحيل `MIGRATION_3_4` لا يحذف الجلسات أو ملفات الصوت القديمة.

## عقود API الجديدة

- `GET /v1/languages`: قائمة اللغات ودعم مزود التمييز الصوتي.
- `POST /v1/semantic-search`: `{query,top_k,segments:[{id,text}]}` → `{kind,matches:[{segment_id,score,text}],model}`؛ تتطلب توثيق Bearer.
- `POST /v1/diarize`: `multipart/form-data` مع `session_id`, `segment_index`, `audio` → `{turns:[{id,speaker,start_ms,end_ms,text}],speaker_scope}`؛ تتطلب Bearer.
- `POST /v1/generate` مع `kind="quiz"`: عناصر تحتوي سؤالاً و4 خيارات و`correct_index` ومعرفات المصدر. لا يحفظ الخادم إجاباته؛ تُحفظ محلياً.
- `POST /v1/translate`: أضيف قبول 14 لغة بدلاً من لغتين فقط.

## الخصوصية

- `local`: تسجيل، قراءة، بحث لفظي، مراجعة وتصدير محلي، دون رفع بيانات.
- `cloud/auto`: **لا يسمح أي منهما بالرفع دون `cloudConsent` على مستوى الجلسة**؛ لا يتوافر نموذج تفريغ محلي مضمّن.
- مفاتيح API لا توضع في APK. متغيرات الخادم فقط في `.env.example`، وعلى المشغل تعيين القيم الحقيقية بعيداً عن المصدر.
- يتم الاحتفاظ بوسوم المتحدثين كمعلومات مصدرية، ولا يتم ربط الأشخاص بهويات من خارج الصوت.
- عند الحذف تُمسح البيانات المحلية، ويُرسل طلب حذف للخادم إذا سبق رفعها؛ إذا فشل يحتفظ التطبيق بطلب محلي لإعادة المحاولة يدوياً.

## التشغيل والاختبارات

من جذر المصدر:

```bash
bash scripts/run_offline_checks.sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

لا بد من Android Studio وJDK17 وAndroid SDK35 وGradle واتصال لجلب الاعتماديات. من مجلد `backend/`: `pip install -r requirements-dev.txt` ثم `PYTHONPATH=. pytest -q`. لتفعيل التمييز الصوتي اضبط `NOTEFLOW_DIARIZATION_MODEL` إلى مزود متوافق مع واجهة `diarized_json`. نموذج OpenAI المذكور في الوثائق الرسمية **قديم ومقرر إيقافه 26 فبراير 2027**، لذا يجب استبداله قبل ذلك التاريخ. لا يعمل التمييز افتراضياً عندما يكون المتغير فارغاً.
